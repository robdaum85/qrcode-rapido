# Avisos de terceiros

Este projeto distribui uma cópia local da biblioteca `qrcode` 1.5.1, também
conhecida como `node-qrcode`.

- Projeto: `soldair/node-qrcode`
- Repositório: https://github.com/soldair/node-qrcode
- Versão utilizada: 1.5.1
- Licença: MIT
- Arquivo distribuído: `vendor/qrcode.min.js`
- Licença original: `vendor/qrcode.LICENSE`

A biblioteca credita a implementação `QRCode for JavaScript`, de Kazuhiko
Arase, licenciada sob MIT.

O código do QR Code Rápido também é distribuído sob licença MIT, conforme o
arquivo `LICENSE` na raiz do projeto.
